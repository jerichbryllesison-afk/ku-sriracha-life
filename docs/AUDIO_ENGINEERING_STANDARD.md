# Audio Engineering Standard (Project Ironclad — permanent)

Every feature request is checked for sound. Not every feature needs sound; every sound needs a reason, a position,
a distance behaviour and a lifecycle. Silence and dynamic range are part of the mix.

## Feature checklist (apply automatically)
| Feature added | Check |
|---|---|
| Vehicle | engine profile in `ENGINES` (cylinders, idle/redline, gears or CVT), tyres, skid, horn kind, door/seat, starter, 3-D position, Doppler, voice priority |
| NPC / character | heel-strike footsteps (`char.sfx`), footwear, voice kind (talk/laugh/shout) with cooldown & turn-taking, emote sounds only if physical |
| Building / area | ambience zone contribution (crowd, hum, enclosure → reverb send), occlusion (collision boxes) |
| Shop / restaurant | activity emitters (sizzle, chatter), interaction one-shots |
| Weather | bed levels (rain, wind), surface wetness for footsteps |
| Animation | sound from animation events (phase crossings), never from free-running timers |
| Multiplayer feature | event replication via `sfx` (whitelisted, rate-limited, distance-filtered) or derived locally from replicated state |
| Vehicle physics | rpm/load/drift/brake/air signals feed the engine voice |

## Rules
- Positional by default: PannerNode (inverse distance), air-absorption low-pass, rear high-cut, occlusion via collision raycast.
- Footsteps are generated by animation heel strikes, alternate feet, stop when the character stops or is airborne.
- Concurrency: engine voices pooled (desktop 8 / mobile 4) with fade in/out; one-shots limited per category; no hard cuts.
- No per-frame allocations in audio update paths; distant updates throttled; nodes disconnected on end.
- Mix: categories master / music / ambient / footsteps / vehicles / npc / ui / effects / voice; limiter on master; ducking
  for phone / menus / map; per-category volumes saved in settings.
- Mobile: AudioContext resumed only from a user gesture; suspended in background tabs; low-cost profile (no HRTF, shorter IR).
- Assets: only original synthesis or properly licensed files; record licence in `docs/AUDIO_ARCHITECTURE.md`. No sounds from
  commercial games, no voice imitation of real people. Placeholders must be labelled as such.
- Report only measured/verified results (see tests in `docs/AUDIO_ARCHITECTURE.md`).
- Night audio is out of scope: the game has no night time by design.
